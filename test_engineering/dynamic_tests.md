# Dynamic Tests

Dynamic testler yazılımı çalıştırarak davranışı doğrular.

## Test seviyeleri

- Unit test
- Integration test
- System/E2E test
- Performance test
- Security test

## İyi uygulamalar

- Testler deterministik olmalı
- Fixture yönetimi sade olmalı
- Kritik kullanıcı akışları e2e ile korunmalı
