# Security Belgeler

Bu bölüm; güvenliği ürün sonrası eklenen bir katman olarak değil, tasarımın başından itibaren uygulanan bir mühendislik disiplini olarak ele alır.

## Kapsam

- Uygulama güvenliği
- Altyapı güvenliği
- Kimlik ve erişim yönetimi
- Güvenlik operasyonları

## Öncelikli başlıklar

1. Threat modeling
2. Secret management
3. Least privilege
4. Vulnerability management
5. Incident response

## Güvenlikte minimum standart

- Kimlik doğrulama ve yetkilendirme ayrıştırılmış olmalı
- Kritik veriler transit + at-rest şifreli olmalı
- Güvenlik logları merkezi toplanmalı
- Düzenli dependency ve container taraması yapılmalı
