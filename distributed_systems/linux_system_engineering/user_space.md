# User Space

User space; uygulamaların çekirdekten izole çalıştığı katmandır.

## Temel konular

- Process lifecycle
- File descriptor yönetimi
- IPC mekanizmaları
- Service supervision

## Operasyonel odak

- Log yönetimi
- Resource limitleri (ulimit/cgroup)
- Troubleshooting araçları (strace, lsof, ss)
