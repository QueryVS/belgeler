# Kernel Space

Kernel space; işletim sistemi çekirdeğinin donanım ve kritik kaynak yönetimini yaptığı ayrıcalıklı alandır.

## Temel konular

- Process scheduling
- Memory management
- Syscall mekanizması
- Device driver modeli

## Mühendislik notu

Kernel seviyesine inmeden önce user-space çözümlemenin sınırları netleştirilmelidir.
