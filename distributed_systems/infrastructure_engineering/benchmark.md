# Benchmark

Benchmark; sistemin kapasite ve performans sınırlarını ölçmek için kontrollü test sürecidir.

## Hedef metrikler

- Throughput
- P95/P99 latency
- Error rate
- Resource utilization

## Uygulama adımları

1. Gerçekçi workload tanımla
2. Baseline ölç
3. Değişikliği uygula
4. Sonuçları karşılaştır
5. Regresyon varsa geri al
