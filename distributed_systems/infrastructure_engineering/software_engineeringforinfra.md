# Software Engineering for Infrastructure

Altyapı ekipleri de yazılım üretir: controller'lar, otomasyon script'leri, operator'lar ve policy kodu.

## Prensipler

- Idempotent otomasyon
- Test edilebilir IaC
- Güvenli varsayılanlar
- Değişikliklerin kod incelemeden geçmesi

## Kalite gereksinimi

- Unit test + integration test
- Dry-run/plan çıktısı
- Rollback ve drift yönetimi
