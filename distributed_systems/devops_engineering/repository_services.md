# Artifact Repository Services

Derlenmiş paketler, container imajları ve bağımlılıkların güvenli depolanması için kullanılır.

## Neden gerekli?

- Tedarik zinciri güvenliği
- Sürüm tutarlılığı
- Hızlı rollback

## Minimum kontroller

- Immutable tag politikası
- Retention policy
- Vulnerability scanning
