# Git Repository Services

## Neden önemli?

Kaynak kodu tek doğru kaynakta tutmak, erişim kontrolü ve inceleme süreçlerini standardize eder.

## Temel yetenekler

- Branch protection
- Merge request / pull request akışları
- Code owners
- Signed commit ve audit log

## Operasyon önerisi

- Main branch'e doğrudan push kapat
- Zorunlu review + CI şartı uygula
